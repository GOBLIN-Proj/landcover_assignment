landcover_assignment.resource_manager.units

Unit conversions for landcover_assignment, kept in one place (the same pattern as landcover_lca).

The package database stores every value as published, in the source’s unit (CRT 2026 and NID 2026 areas in kha), and its column_metadata table names that unit for every column. The readers in database_manager convert on read, column by column, using the table below. So a number in the database can be checked against its source by eye, and every conversion happens here.

Model units (what the calculations receive):

areas ha shares dimensionless (an area divided by an area, so its unit cancels)

To add a column with a new unit, record the unit in column_metadata (tools/build_database.py) and add it here.
