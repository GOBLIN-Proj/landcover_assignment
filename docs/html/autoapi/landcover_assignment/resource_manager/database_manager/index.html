landcover_assignment.resource_manager.database_manager

The DataManager class serves as an interface to interact with a land use database, facilitating the retrieval of various datasets related to national land cover areas such as forests, wetlands, croplands, grasslands, and settlements, as well as soil yield mappings for forests. This class is designed to support environmental data analysis and modeling tasks by providing structured access to key land use datasets.

ivar database_dir:

Directory where the database file is located.

vartype database_dir:

str

ivar engine:

SQLAlchemy engine object for database connection.

vartype engine:

sqlalchemy.engine.Engine

_to_model_units(table, dataframe)

Converts each column of dataframe from the unit recorded for it in the database’s column_metadata table to the model unit (areas: kha to ha), using landcover_assignment.resource_manager.units. Keys and labels (units year, label, group) are left as they are.

get_national_inventory_areas()

Retrieves the national land area by land category (CRT 2026 Table4.1 final area, 1990-2024) and converts its areas from kha to ha.

Useful as a quick national check: the categories add up to the national land area (7,111,785 ha) in every year. Labels are the inventory’s (e.g. “Grassland (managed)(2)”); the Area_kha column name is kept from 0.4.0 but holds ha after conversion.

Returns:

indexed by Year, with Land_cover and Area_kha (in ha).

Return type:

pandas.DataFrame
