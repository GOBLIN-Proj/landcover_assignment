landcover_assignment.geo_landcover_assignment.geo_afforestation

Afforestation input for the Carbon Budget Model (cbm_runner) in the catchment tree.

It is the national landcover_assignment.afforestation.Afforestation, except that the scenario table is validated when the class is created (ScenarioDataFetcher(..., validate_on_init=True)). The import path and the constructor are unchanged: Afforestation(calibration_year, target_year, scenario_inputs_df, transition_matrix).
