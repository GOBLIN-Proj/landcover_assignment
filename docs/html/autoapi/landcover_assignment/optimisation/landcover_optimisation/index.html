landcover_assignment.optimisation.landcover_optimisation

Allocates a scenario’s spared mineral grassland between land-use targets with a small Pyomo model, solved by the open-source HiGHS solver.

The model

All areas are divided by the available mineral area A, so the model works in shares of A. This keeps the problem well scaled; the results are multiplied back to hectares.

Sets

LAND_USES: the land uses with a target (currently forest and cropland). It is built from target_areas, so adding a land use needs no code change.

Parameters

target[i]: the target area of land use i (share of A). area_available: 1 (all of A).

Variables

allocation[i] >= 0: area allocated to land use i. fallback >= 0: area allocated to no target, returned as farmable_condition.

Objective (minimise)

sum over i with target[i] > 0 of (allocation[i] - target[i])^2 / target[i], plus fallback^2.

Constraints

use_all_area: sum of allocation[i] + fallback = area_available. cap_at_target[i]: allocation[i] <= target[i].

What this gives:

  • If the targets fit within the available area, every target is met and the rest goes to farmable_condition.

  • If they don’t fit, farmable_condition is 0 and every target is cut by the same percentage: dividing each squared shortfall by its target makes the shortfalls proportional to the targets, so a small target (say crop 1%) is not wiped out before a large one (decision 2026-11-27, step 7 item 13; the earlier unweighted objective cut every target by the same hectares).

  • Land uses with a 0 target are left out of the objective; cap_at_target keeps them at 0.

  • The objective is strictly convex in the land uses with a target, so the solution is unique. Any correct solver gives the same answer.

Extending the model

optimise_mineral_spared_area_distribution accepts extra_constraints: functions that take the Pyomo model and add components to it. They are added after the standard ones, so they can use model.LAND_USES, model.target, model.allocation and model.fallback. For example, a cap on cropland:

def cap_cropland(model):
    model.cap_cropland = pyo.Constraint(expr=model.allocation["cropland"] <= 0.1)   # share of A

LandCoverOptimisation().optimise_mineral_spared_area_distribution(area, targets, extra_constraints=[cap_cropland])

A new land use (for example willow) needs only a new entry in target_areas.
